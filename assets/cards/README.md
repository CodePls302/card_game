Card art goes here, one PNG per card, named after the card in lowercase with
underscores: "Stone Golem" -> `stone_golem.png`. Any card without a file is
drawn with a coloured placeholder. Art is shown at 88x60, so anything with that
shape (e.g. 352x240) works best.

The current art was generated from game-icons.net icons; see `CREDITS.md`
and `tools/make_card_art.sh`. To use your own art for a card, just replace
its PNG (and update `CREDITS.md`).
